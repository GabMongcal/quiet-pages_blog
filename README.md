✨ Quiet Pages ✨

Quiet Pages is a minimalist blog platform built with modern web technologies.
It allows users to write, share, and interact with blog posts in a calm, clean, and distraction-free environment.

This project was developed as part of a technical assessment, with a focus on clean UI, proper state management, and real-world application features.

/_----------------------------------------------/_

🛠 Tech Stack
• React with TypeScript
• Vite for fast development and build tooling
• Tailwind CSS for modern, utility-first styling
• Redux Toolkit for global state management
• Supabase for:
• Authentication
• Database
• File Storage (images)

/_----------------------------------------------/_

✨ Features
• User authentication using email or username
• Global state management with Redux
• Create, edit, and delete blog posts
• Owner-only access for editing and deleting posts
• Image upload with preview and replacement support
• Automatic cleanup of replaced images in storage
• Comment system with image support
• Owner-only comment deletion
• Upload and posting indicators for better UX
• Protected routes for authenticated users only
• Clean, minimalist, and assessment-ready UI

/_----------------------------------------------/_

Getting Started

1. Install dependencies
   npm install

2. Run the development server
   npm run dev

The app will be available at: http://localhost:5173

Project Notes
• Redux is used to manage shared application state such as authentication and user data.
• Supabase handles backend services including authentication, database operations, and image storage.
• Tailwind CSS is used consistently across all pages for a unified design system.
• The project prioritizes clarity, maintainability, and user experience over over-design.
